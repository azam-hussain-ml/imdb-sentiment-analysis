# IMDb Sentiment Analysis Classifier
Built a binary sentiment classifier on 50K IMDb reviews using **TF-IDF** for feature extraction and **Logistic Regression**. Achieved **89% accuracy**, with evaluation via precision, recall, and F1-score. Supports real-time predictions!
## 🚀 Features
- TF-IDF vectorization on preprocessed text
- Logistic Regression model (trained on 25K train/25K test split)
- ~89% accuracy; high precision/recall on positive/negative classes
- Real-time prediction via Streamlit UI
## 📊 Results
| Metric     | Score  |
|------------|--------|
| Accuracy  | 89%   |
| Precision | 0.89 |
| Recall    | 0.88 |
| F1-Score  | 0.88 |
